# KINET

**Edit the world without breaking it.** An AI simulation compiler that turns natural-language instructions into interactive 3D environments with executable, world-enforced action contracts.

Victoria VR AI Builder Hackathon 2026 entry.

## The problem

AI can generate a plausible 3D world, but it can't be trusted to change it safely. Ask an AI editor to "move the red key to the balcony" and it may silently break the door that needs that key, invalidate a puzzle dependency, or make an objective impossible.

Generative world models (Genie 4, SimWorld, GoliathOS) already admit this: scene drift and broken object permanence across edits are open failures.

KINET closes that gap: **the AI proposes an action; a deterministic runtime enforces it against the live world state. The world — not the model's interpretation — decides what actually happens.**

## What it does

- **Natural-language generation:** describe a factory floor ("a conveyor, a worker, a danger zone, a maintenance panel") and KINET compiles it into a live Three.js scene with a semantic object model (stable IDs, types, properties, relationships).
- **Intelligent interaction:** chat with an AI Floor Supervisor. It proposes typed actions (`restart_conveyor`, `stop_conveyor`, `activate_warning`, `open_maintenance_panel`, `release_maintenance_lock`, `engage_maintenance_lock`).
- **Runtime enforcement:** every proposed action is checked against identity, object, action, spatial context, and live state preconditions before the world changes. Allowed actions mutate the world; rejected ones leave it untouched.
- **Action receipts:** every attempt is logged — who asked, what action, which rule was evaluated, allowed/blocked, reason, and state before/after. Generated by the runtime, never fabricated by the model.
- **Natural-language editing:** move the worker into/out of the danger zone, engage/release the maintenance lock, then watch the same action flip from blocked to allowed as the world state changes.

## The demo story

1. **Generation:** "Build a factory floor with a conveyor, a worker, a marked danger zone, and a maintenance panel." The scene compiles and runs.
2. **Interaction:** Visitor moves the worker into the danger zone, then tells the supervisor "restart the conveyor."
3. **Control:** KINET rejects it — a worker is still in the hazard zone. The conveyor stays stopped. The receipt explains why.
4. **State change:** Visitor releases the maintenance lock. Still blocked (hazard not empty). Visitor moves the worker back to the floor.
5. **Verification:** "Restart the conveyor" — now permitted. The conveyor starts. The receipt shows the state transition.

This is a simulated training environment, not a certified safety system — but it demonstrates the principle: an AI character that can genuinely act in a world without bypassing its rules.

## Tech stack

- React-free vanilla JS + Three.js (ES modules via esm.sh, no build step)
- Zustand for simulation state
- Zod for contract schema validation
- LLM (NVIDIA NIM / OpenAI-compatible) for intent compilation, with a deterministic rule-based fallback so the demo never dead-ends

## Local run

```bash
# Serve the static folder (no install required)
python3 -m http.server 8090
# open http://localhost:8090/index.html
```

The page is fully static: Three.js, zustand and zod load from esm.sh. No API key is required — the built-in rule-based compiler handles all demonstrated commands. Paste an NVIDIA NIM key (`nvapi-…`) into the console to use the real LLM compiler.
